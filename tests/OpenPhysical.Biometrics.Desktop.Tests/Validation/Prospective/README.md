# Full-attempt evaluation contracts

The policy-specific RawHull0/whitened evaluation runner is retired. Its exact
failed execution, copied runner sources, pinned oracle and recovered source bytes
are preserved under ignored `artifacts/research-archive/failed-raw-hull0-final-92f093ece942.zip`.
The archive inventory explicitly records incomplete source recovery. Raw public
corpus images and exported biometric templates are not included.

The active code here retains generic full-attempt ledger, source-freeze,
typed-error and JSON serialization contracts. It contains no dataset scoring
entrypoint and does not reinterpret the failed policy as the new contact contour.
A future evaluator requires a separately named, prespecified policy and new
validation data. No current policy has a passing independent matching result.
