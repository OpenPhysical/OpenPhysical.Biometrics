# FS50 hardware vectors, 2026-11-10

This fixture retains the actual FS50 descriptor (64 bytes), controls (64 bytes),
and calibration (4,352 bytes), plus raw and corrected empty-platen images at
exposures 0, 64, 128, 200, and 255. Calibration was read in two identical complete
passes. The manifest contains no serial number or person identifier.

All five corrected images were visually reviewed as empty glass without
fingerprint ridge patterns and reported zero contact area. These fixtures contain
no captured human fingerprint. The original raw and corrected images are stored
as lossless gzip files with a zero gzip timestamp for reproducibility.

`hardware-vectors.json` preserves the original capture-time SHA-256 digests,
nine factory-map observations, acquisition exposures, and three synthetic-pattern
digests. These expected values are copied from the captured manifest rather than
regenerated by the managed tests.

An independent verification used the pre-existing Python `geometry.py` factory
mapping and OpenCV 5 cubic remapping. Every corrected byte matched for all five
actual empty-platen frames and three synthetic frames, as recorded in
`independent-verification.json`. Synthetic sources use the shared parity-test
generator with the original capture recipes: horizontal `x % 256`, vertical
`y % 256`, and an alternating checkerboard with eight-pixel squares.

The regression tests verify metadata integrity, the nine map observations, every
actual corrected pixel, preserved raw pixels, contact results, and the independent
synthetic digests. They do not open or require a scanner.
