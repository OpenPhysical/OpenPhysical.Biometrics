# Current product direction

The authoritative [cross-product specification](https://github.com/OpenPhysical/OpenPhysical.Net/blob/studio-release/docs/architecture/studio-products.md) defines Enrollment Studio, Issuer Studio, Issuance Server and Directory. Both Studios may personalize approved managed cards using the shared executor and separate server authorization.

The [pre-split record](history/2026-11-15-DESKTOP.md) preserves earlier implementation and qualification evidence. It is not the current release guide.
