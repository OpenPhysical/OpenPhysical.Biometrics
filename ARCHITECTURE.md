# OpenPhysical.Biometrics architecture

The [architecture guide](docs/ARCHITECTURE.md) describes the current package graph,
biometric/signature responsibility boundary, middleware integration, and the
current capture/issuance separation and historical package-extraction sequence. The [hosted test issuance plan](../OpenPhysical.Net/docs/planning/hosted-test-issuance.md) defines planned product behavior.

[Workflow examples](examples/README.md) explain capture, enrollment, inspection,
signing, and comparison. [Portrait preparation](docs/PIV-PORTRAITS.md) describes
the MediaPipe model and Full Frontal geometry.
